# Video

`token-burn.mp4` is the 40-second square parody advert, and `poster.png` is the Overreaching buzz on the wrist: H.264 and AAC at 1080 × 1080, normalised to -14 LUFS.

Both are rendered by `make video` from the Remotion project in [`video/`](../../../video/README.md), which explains how the stills, the watch screens, the voice and the music were made.
The watch screens are real Token Burn captures from the Connect IQ simulator, fed with made-up joke numbers rather than anyone's usage.

The README plays a lighter re-encode of the same cut (7.8 MB at CRF 22), uploaded as a GitHub attachment; the file here is the full-quality original.
