# Video

`token-burn.mp4` is the 40-second square parody advert, and `poster.png` is its opening shot: a runner on the beach at dawn.
It is H.264 and AAC at 1080 × 1080 and 30 fps, with audio normalised to -14 LUFS.

Both are rendered by `make video` from the Remotion project in [`video/`](../../../video/README.md), which explains how the footage, the watch screens, the voice and the music come together.
The six lifestyle shots are Pexels stock footage, listed in the [credits](../../../video/CREDITS.md); the watch screens are real Token Burn captures from the Connect IQ simulator, fed with made-up joke numbers rather than anyone's usage.

The root README plays this same file, uploaded as a GitHub attachment.
